FlowPost Desktop Agent

Подключение локального браузера

Agent открывает отдельный браузер на вашем компьютере, чтобы FlowPost мог выполнять задачи публикации без передачи cookies и паролей на сервер.

Подключить Agent

Ваши данные остаются на вашем компьютере

FlowPost Agent запускает браузер локально на вашем устройстве. Сессии площадок, cookies и авторизация в Dzen/VC.ru хранятся в локальном профиле браузера и не передаются на сервер FlowPost.

  • Браузер открывается на вашем компьютере, а не на сервере.
  • Логины и пароли от площадок не передаются в FlowPost.
  • Cookies и сессии хранятся локально в профиле Agent.
  • FlowPost получает только технические статусы выполнения задач.
  • Вы можете отключить Agent и удалить локальный профиль браузера.
  • Agent работает только после подключения через одноразовый код.

Что FlowPost НЕ получает

  • пароль от Dzen/VC.ru
  • cookies площадок
  • доступ к вашему основному браузеру
  • данные банковской карты
  • личные файлы на компьютере

Что FlowPost получает

  • ID задачи публикации
  • выбранную платформу
  • статус выполнения задачи
  • технические логи без паролей и cookies
  • результат выполнения: успешно / ошибка
